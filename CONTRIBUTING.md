# Contributing to Le Boat

Start with an issue describing the design question or proposed change. Include units, configuration, source/provenance and evidence. Keep editable CAD alongside meaningful neutral exports and identify revisions. Avoid unreviewable binary-only changes when a drawing, parameter diff or screenshot can explain them.

For test reports include procedure, conditions, measured values, uncertainty and failures. For code include a reproducible example or appropriate verification. For physical changes state how mass, flotation, draft, stability, seals and load paths are affected. Disclose substantial AI assistance using the journal template.

By submitting a contribution for inclusion, you agree to license it under the applicable terms in LICENSE.md, retain third-party notices and confirm you have authority to do so. You keep your copyright. This is not a copyright assignment or a grant allowing the maintainer to sell separate rights to your contribution; commercial permissions may require each relevant rights holder's agreement.

Do not add purchased plans, copied proprietary geometry, private conversations, credentials or assets without suitable permission. Cite reference designs without suggesting endorsement.

Project documents are the source for the site reference pages. After editing them install the dependency as described in README, then run `.venv/bin/python scripts/build_site.py`, preview `docs/`, and include the generated changes. Keep journal entries dated and distinguish planned work from completed work.
