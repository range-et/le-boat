# Contributing

This is a collaborative boat build and journal.
Suggestions, design ideas, shared experiments and build notes are welcome.

You can [open an issue](https://github.com/range-et/le-boat/issues) to discuss an idea or ask a question.
Pull requests are welcome for CAD, code, documentation and website changes.
For a design or test result, include enough context for others to understand what you tried.
Editable files, dimensions, materials, settings and photos can help.
Record significant AI assistance where relevant.

The build uses git-cad for CAD management, Hawa for CFD and Monad System for the website UI.
The [project notes](project/decisions.md) show where things stand.

## Website edits

Use short, direct English.
Keep project notes descriptive and distinguish ideas from completed work.
The site documents this build and the choices made during it.

Follow the build steps in [README.md](README.md) after editing the Markdown sources.
Include regenerated pages with your changes.
