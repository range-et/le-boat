Tool notes

Updated November 8, 2026.

CAD

I’m using Rhino, Grasshopper and Blender for geometry, with git-cad for CAD management. The git-cad project is in specification/prototype development. Its setup for this boat remains pending. Reference revision: 97b8143.

Print preparation

I’m using Orca Slicer to prepare prints for the Bambu A1 mini. Print settings and orientations will be recorded with the build notes.

CFD

Hawa will help explore flow around the hull, keel and rudder. I want to compare shapes as the design develops, including their effects on drag and lateral force. Weight, stability, shallow draft and printability will also affect the choices. Boat geometry and CFD cases are still ahead.

The journal will include geometry revisions, case settings and results when these experiments start. A submerged flow study has limits, including the absence of free-surface waves and sail-driven motion. Physical tests will provide more information about the completed boat. Reference revision: c04d7db.

Website

The site uses Monad System for its UI. The CSS, JavaScript and MIT license are stored in docs/assets/monad/. Vendored revision: 358d055. Project CSS adds the page layout and responsive behaviour.

For updates, copy both build files and the license from one upstream revision. Keep generated Monad files unchanged and update this version record.
