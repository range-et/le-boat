002 — Tool selection and documentation update

November 8, 2026 · Phase: brief and website

The owner selected git-cad for CAD management, Monad System for website UI, and Hawa for CFD. git-cad remains in specification/prototype development. Its Le Boat setup awaits an available workflow. Hull, keel and rudder CFD cases remain pending.

The website now uses pinned Monad CSS, JavaScript, tokens and components. The upstream MIT license accompanies these files. The documentation defines baseline comparisons, optimization measures, constraints and required evidence. Collaboration remains open through issues and pull requests.

The owner requested short, direct English. The site and project documents now use literal descriptions and shorter sentences. The homepage title is “RC sailboat for Love Park”.

AI use: Codex reviewed the selected repositories and changed the documentation and website. The Monad ASD-STE100 skill guided the language review. This review does not establish full compliance with the official ASD dictionary. Boat geometry, simulation results, fabrication and physical tests remain pending.
