002 — Tools for the build

November 8, 2026 · Early design

I’ve selected git-cad for CAD management, Hawa for CFD and Monad System for the website UI. Rhino and Grasshopper will be the main geometry tools.

The website now uses Monad’s CSS, JavaScript and theme controls. The source files and MIT license are included in the repository.

git-cad is in specification/prototype development, so its setup for this boat is still ahead. Hawa will help explore flow around the hull, keel and rudder once there is geometry to work with. I’ll record the design changes and experiments here as they happen.

Ideas and contributions are welcome. Codex helped with the tool review and website changes.
