Le Boat

Le Boat is an experimental RC sailboat for Love Park in Toronto. Wind provides all propulsion. A battery powers the radio receiver and servos for steering and sail trim.

The project covers CAD, home fabrication, assembly, CFD and water tests. The DragonForce 65 provides an initial design reference. We will select dimensions from equipment mass, stability, pond depth and printer limits.

Status: design brief and research. The repository contains documentation and the website. Boat geometry, fabrication and water tests are pending.

Sailing site

Love Park is at 96 Queens Quay West. Waterfront Toronto lists a pond depth of 20–60 cm, approximately 8–24 inches. We must measure route clearances and check operating rules before sailing. See site research for sources and open questions.

Optimization

Compare hull and appendage designs against a recorded baseline. Measure drag, lateral force, stability, mass, draft, print cost and sailing control. Keep test conditions fixed when comparing designs. Select improvements within the safety and fabrication constraints. Record simulation uncertainty and check selected designs with physical tests.

Website development

GitHub Pages serves the static files in docs/. Monad supplies the website UI styles and theme controls. The pinned files and MIT license are in docs/assets/monad/.

  1. Create the build environment: python3 -m venv .venv.
  2. Install the build dependency: .venv/bin/python -m pip install -r requirements-site.txt.
  3. Build reference pages: .venv/bin/python scripts/build_site.py.
  4. Start a preview: python3 -m http.server 8000 --directory docs.
  5. Open http://localhost:8000.

Pushes to main build and deploy the site through GitHub Actions.
