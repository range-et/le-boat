# Built with AI, deliberately

Le Boat is an experiment in human–AI co-creation as well as a sailing project. We want to learn which tools help turn an idea into a physical object, where they fail, and how to keep decisions understandable to another builder.

Codex assisted with the initial research, brief expansion, repository documentation and GitHub Pages website. Rhino is the intended CAD environment. Parametric modelling and Hawa flow studies are planned; no CAD, simulation or physical build results are claimed in this initial record.

## Working practice

Keep proposals, calculated results, simulated results and physical measurements explicitly labelled. Check units, coordinate systems, mass accounting and boundary conditions. Review generated code and inspect geometry before fabrication. A convincing image is not a watertight solid; a plausible paragraph is not a test result.

For substantial AI-assisted changes record the tool/model when known, task, affected files, important assumptions, human review and remaining uncertainty. Use the [journal template](../templates/journal-entry.md). Do not invent a model version or claim a human check happened when it did not. Include concise prompt summaries where useful; exclude secrets, private conversations and unrelated personal information.

Humans decide what gets built, operated and published. Tool providers are not engineering certifiers or project endorsers. AI-assisted output may have uncertain provenance or protectability; licenses cover only rights the contributors can actually grant. Check third-party references and licenses before incorporating assets or geometry. The DragonForce 65 reference is inspiration, not a claim of affiliation or permission to copy its design.

Keep the difficult bits visible: rejected geometry, mass overruns, print failures, incorrect assumptions and unsuccessful sails. Useful co-creation evidence is a traceable decision and its outcome.
