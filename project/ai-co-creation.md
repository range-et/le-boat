# AI use

People and AI tools develop Le Boat together.
The project records how these tools affect design work, fabrication and tests.
Codex helped with research, documentation and website code.
Amp Code also helped with earlier coding.
CAD work, boat simulations and physical tests remain pending.

## Evidence records

Label each result as proposed, calculated, simulated or measured.
Check units, coordinates, component masses and boundary conditions.
Review generated code before use.
Check geometry before fabrication.
Record failed designs and tests with their conditions.

For significant AI contributions, record:

- Tool and model, if known.
- Task and relevant prompt summary.
- Files and assumptions affected.
- Completed human checks.
- Remaining uncertainty.

Use the [journal template](../templates/journal-entry.md).
Exclude credentials, private conversations and unrelated personal information.
Record only checks that someone completed.

## Responsibility and source material

People decide what to build, operate and publish.
Check third-party sources and licenses before adding code, assets or geometry.
AI output can contain errors and uncertain source material.
Project licenses cover only rights that contributors can grant.
Tool use does not establish engineering approval or provider endorsement.
